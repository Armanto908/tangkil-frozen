## Fitur

- Katalog sapi, ayam, kambing, olahan, dan bumbu marinasi
- Pilih berat & kemasan vakum
- Keranjang + guest checkout
- Estimasi ongkir GoSend / GrabExpress / Paxel
- Kalkulator porsi (BBQ, hajatan, shabu)
- Paket bundling & langganan box
- Konfirmasi pesanan ke WhatsApp admin

## Live

Situs: [tangkil-frozen.netlify.app](https://tangkil-frozen.netlify.app)

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka pratinjau di port yang dipakai script `dev` (8080).

```bash
npm run build
npm run typecheck
```
